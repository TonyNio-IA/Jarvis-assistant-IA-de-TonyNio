Windows a bloqué le fichier d'installation de Jarvis ?

C'est la protection « Contrôle intelligent des applications » de Windows 11. Elle bloque les fichiers récents téléchargés avec le navigateur. Rien n'est cassé, et il ne faut rien désactiver.

1. Appuie sur la touche Windows + X, puis choisis Terminal (ou Windows PowerShell).
2. Copie la ligne ci-dessous, colle-la dans la fenêtre (clic droit), puis appuie sur Entrée :

$f="$env:TEMP\Installer-Jarvis.bat"; iwr https://github.com/TonyNio-IA/Jarvis-assistant-IA-de-TonyNio/releases/latest/download/Installer-Jarvis.bat -OutFile $f; Start-Process $f

3. La fenêtre d'installation de Jarvis s'ouvre : continue normalement.
